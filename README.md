# mindray-bc2800vet-parser

Приём результатов гематологического анализатора **Mindray BC-2800Vet** по COM-порту,
формирование бланка ОАК в PDF и автоматическая печать.

```
COM-порт (9600 7-O-1) → парсер кадров → HTML-бланк → PDF (в памяти) → lp → принтер
```

PDF на диск не сохраняется. Бланк оформлен в монохроме для ч/б лазерного принтера.

## Установка и эксплуатация

1. Подключить анализатор через USB-COM переходник (обычно `/dev/ttyUSB0`).
2. Установить службу (без sudo):
   ```bash
   ./deploy/install.sh
   ```
3. Один раз выдать права (затем перезайти в систему):
   ```bash
   sudo usermod -aG dialout $USER     # доступ к COM-порту
   sudo loginctl enable-linger $USER  # служба работает без входа в систему
   ```
4. Настройки — `~/.config/oak-printer.env` (образец: `deploy/oak-printer.env.example`):

   | Переменная | Назначение |
   |---|---|
   | `DEVICE`   | COM-порт; надёжнее `/dev/serial/by-id/...` |
   | `PRINTER`  | очередь CUPS (`lpstat -p`) |
   | `DOCTOR`   | врач в шапке бланка |

   После изменения: `systemctl --user restart oak-printer`.

   Вид животного определяется из кадра анализатора (коды — `src/protocol/species.js`).
   Референсные интервалы пока есть только для собак и кошек; для остальных видов
   и неизвестного кода колонки «Интервал»/«Референс» на бланке пустые.

**Управление:**
```bash
systemctl --user status oak-printer     # статус
journalctl --user -u oak-printer -f     # журнал в реальном времени
```

Служба перезапускается автоматически (каждые 5 с), если порт недоступен или кабель отключён.
Если проба не напечаталась (нет бумаги, принтер выключен), в журнале будет запись с номером
пробы — переотправьте результат с анализатора.

## Разработка

```bash
npm test                    # тесты на реальных захватах из materials/captures
npm run render:offline      # захват → PDF в out/ без устройства и принтера (удалите out/ после проверки)
npm run record              # запись сырого потока с порта в materials/captures
node scripts/parse-capture.js <capture.bin>   # захват → JSON
```
