# Хендофф: Отчёт об общем анализе крови (ОАК)

## Обзор
Печатный A4-документ ветеринарной лаборатории — бланк результата общего
анализа крови (гематология). Показывает шапку с данными пациента/пробы,
сгруппированную таблицу показателей (Лейкоциты / Эритроциты / Тромбоциты)
и горизонтальную шкалу с маркером, показывающую положение значения внутри
референсного интервала. Значения вне нормы помечаются цветом и стрелкой ↑/↓.

## О файлах дизайна
Файлы в этом пакете — **референс-дизайн, сделанный в HTML**. Это прототип,
показывающий желаемый вид и поведение, а **не продакшн-код для прямого
копирования**. Задача — **воссоздать этот дизайн в целевой кодовой базе**
(React/Vue/Svelte/нативное и т. д.) на её собственных паттернах и
библиотеках. Если окружения ещё нет — выбрать подходящий фреймворк и
реализовать там.

Технически прототип написан как «Design Component» (формат `.dc.html`) —
шаблон + класс логики. При переносе берите из него **разметку, стили и
логику расчёта шкал**; обёртку формата `.dc.html` воспроизводить не нужно.

## Уровень проработки (Fidelity)
**High-fidelity (hifi).** Финальные цвета, типографика, отступы и
поведение. UI следует воссоздать пиксель-в-пиксель средствами вашей
кодовой базы. Данные пациента и значения — пример, подлежат замене на
реальные.

  2026-06-16 09:20».

## Логика расчёта шкалы (ключевое)
Для каждого показателя заданы `min` и `max` референса и числовое
значение `n`. Расчёт:

```
status = (n < min) ? 'low' : (n > max) ? 'high' : 'normal'
pos%   = clamp( 20 + ((n - min) / (max - min)) * 60 , 4 , 96 )   // left маркера
arrow  = high ? '↑' : low ? '↓' : ''
flag   = status !== 'normal'
markerColor = flag ? '#D1495B' : '#2E8C97'
valueColor  = flag ? '#D1495B' : '#15252A'
```

То есть нижняя граница нормы → 20 % трека, верхняя → 80 %; значения вне
нормы выходят за полосу нормы и упираются в края (clamp 4–96 %).

## Взаимодействия и поведение
- Документ статичный (печатный бланк) — интерактивных состояний нет.
- При печати (`@media print`): скрывается экранная подпись над
  страницей (`[data-noprint]`), убирается фон/тень/скругление, страница
  печатается как A4 с полями 10 mm.
- Параметризация (опционально, было реализовано как «tweaks»):
  - `reportTitle` — текст заголовка (по умолчанию «Отчёт об общем
    анализе крови»).
  - `showBars` — показывать/скрывать колонку со шкалами (boolean).

## Состояние (State)
- Чистое отображение по входным данным; собственного UI-состояния нет.
- Входные данные: массив групп `[{ name, rows: [{ code, name, v, n,
  unit, min, max, range }] }]`. `v` — строковое отображение значения
  (сохраняет формат, напр. «3.10»), `n` — число для расчёта, `range` —
  строка интервала для показа (напр. «5.5–19.5»).
